# 2027 Reset Kit — bio-link sales page

Static one-page site (index.html + img/) that sells the 2027 Reset Kit.
Checkout and file delivery run through Shopify (The Random Store) with the Digital Products app.

- To change the checkout link: edit `BUY_URL` near the bottom of `index.html`.
- Deployed on Vercel from the `reset-kit-site` branch. This branch is separate from the store code on `main`.
